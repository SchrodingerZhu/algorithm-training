# 13 · 子树 RMQ：DFS 序与点修改

给定一棵根固定为 `0` 的树，每个节点都有一个点权。我们要交替执行两件事：修改某个节点的权值，查询某个节点的整棵子树中的最小点权。

树上的子树看起来不是数组区间，但如果按合适的顺序给节点重新编号，每棵子树就会成为一个连续区间。本题先解释这种编号，再把第 04 题的点修改与区间最小值查询用到树上。

## 题目与函数接口

数组 `parent` 描述一棵非空树，根为节点 `0`，`parent[0] = -1`。对其他节点 `v`，`parent[v]` 是它的父节点。数组 `values[v]` 是节点 `v` 的初始点权。

节点 `v` 的子树包含 **`v` 自身和它的所有后代**。整个处理过程中，根和树的边都保持不变，只有点权会变化。

按输入顺序处理 `operations`：

| 操作 | 含义 | 是否产生答案 |
|---|---|---|
| `{0, v, value}` | 将节点 `v` 的点权赋为 `value`，覆盖原来的值 | 否 |
| `{1, v, 0}` | 查询节点 `v` 的整棵子树中的最小点权 | 是 |

查询操作的第三项只是占位，不参与计算。返回的是最小**权值**，不是取得最小值的节点编号；多个节点权值相同时不需要选择其中一个节点。

在 `Solution` 类中实现：

```cpp
std::vector<long long>
subtreeMin(const std::vector<int> &parent,
           const std::vector<long long> &values,
           const std::vector<std::array<long long, 3>> &operations);
```

返回数组只保存查询操作的答案，顺序与这些查询在输入中出现的顺序相同。只需完成函数及其辅助代码，不需要编写 `main` 或处理输入输出。

- `1 ≤ n = parent.size() = values.size() ≤ 200000`。
- `0 ≤ operations.size() ≤ 200000`，所有操作中的节点编号均在 `[0, n)` 内。
- 初始点权与赋值的 `value` 都在 `[-10⁹, 10⁹]` 内，允许负数和重复值。
- 输入保证是一棵合法的树，父节点编号不保证小于子节点编号。
- 没有查询操作时返回空数组。同一个 `Solution` 对象的多次调用应独立计算。
- 目标：`O(n)` 预处理，每次操作 `O(log n)`，辅助空间 `O(n)`；另需保存返回数组。

## 先手算一次修改前后的答案

```text
parent = [-1, 0, 0, 1]
values = [ 5, 4, 3, 2]

        0:5
       /   \
     1:4   2:3
     /
   3:2
```

图中 `编号:点权` 表示一个节点。节点 `1` 的子树包含节点 `1, 3`，不包含它的父节点 `0`，也不包含另一条分支中的节点 `2`。

```text
operations = [[1, 1, 0], [0, 3, 8], [1, 1, 0], [1, 0, 0]]
answer     = [2, 4, 3]
```

| 操作 | 本次处理 | 返回值 |
|---|---|---|
| `{1, 1, 0}` | 节点 `1, 3` 的点权是 `4, 2` | `2` |
| `{0, 3, 8}` | 节点 `3` 的点权从 `2` 变为 `8` | 不输出 |
| `{1, 1, 0}` | 同一棵子树的点权现在是 `4, 8` | `4` |
| `{1, 0, 0}` | 根的子树是整棵树，点权为 `5, 4, 3, 8` | `3` |

修改会影响后续查询，但不改变任何节点属于哪棵子树。

## 第一步：只在第一次进入节点时编号

深度优先遍历（DFS）会先处理一个孩子的整棵子树，再处理下一个孩子。令计数器从 `0` 开始，第一次进入节点 `v` 时，把当前计数器记为 `tin[v]`，随后将计数器加一。

在节点 `v` 的所有孩子都处理完、即将离开 `v` 时，把当前计数器记为 `tout[v]`。离开节点时不再增加计数器。

因此，`tin[v]` 是节点在新数组中的位置，`tout[v]` 是它的子树区间的右端点，且这个右端点**不包含在区间内**。

在主例中，若先访问孩子 `1`，再访问孩子 `2`，首次进入的顺序是：

```text
位置：       0  1  2  3
节点编号：   0  1  3  2
初始点权：   5  4  2  3
```

各节点的区间是：

| 节点 `v` | `tin[v]` | `tout[v]` | 区间内的节点 |
|---|---|---|---|
| `0` | `0` | `4` | `0, 1, 3, 2` |
| `1` | `1` | `3` | `1, 3` |
| `2` | `3` | `4` | `2` |
| `3` | `2` | `3` | `3` |

孩子的访问顺序可以不同，只要整个算法使用同一次遍历得到的编号，查询结果就相同。

### 为什么子树一定连续？

第一次进入 `v` 时先记录它自己。随后，DFS 会访问它的所有后代，直到整棵子树处理完才离开 `v`。在这段过程中，不会去访问子树外的节点。

所以从记录 `v` 到离开 `v` 之间新增的编号，恰好属于它的整棵子树，没有遗漏，也没有夹入外部节点。这就是：

```text
v 的子树 ↔ 半开区间 [tin[v], tout[v])
```

如果同时统计了子树节点数 `size[v]`，也可以用 `tout[v] = tin[v] + size[v]` 得到右端点。叶子的区间长度为 `1`，根的区间长度为 `n`。

### 与第 09 题的 Euler Tour 有什么区别？

这里每个节点只占一个位置，数组长度是 `n`。第 09 题为求 LCA，在从孩子返回时还会重复记录父节点，形成长度为 `2n - 1` 的行走序列。

本题需要每个点权恰好对应一个数组位置，使用的是首次进入顺序。不要直接把带重复节点的 LCA 行走序列当成本题的数组。

## 第二步：在新数组上建立线段树

定义展平后的数组：

```text
flat[tin[v]] = values[v]
```

主例的初始数组是 `[5, 4, 2, 3]`。对它建立保存区间最小值的线段树：叶子保存一个位置的点权，内部节点保存两个孩子最小值的较小者。

两个操作现在分别成为：

1. 对 `{0, v, value}`，将数组位置 `tin[v]` 赋为 `value`，并沿线段树向上重新计算最小值。
2. 对 `{1, v, 0}`，查询数组区间 `[tin[v], tout[v])` 的最小值。

如果复用第 04 题的线段树时，其接口接受的是闭区间，就传入 `[tin[v], tout[v] - 1]`。先确定线段树的区间约定，再做转换，不要在不同操作中混用。

例如把节点 `3` 赋为 `8`，修改的是位置 `tin[3] = 2`，数组成为 `[5, 4, 8, 3]`。节点 `1` 的查询仍使用位置区间 `[1, 3)`，取出的就是 `4, 8`。

查询的累积答案应从正无穷开始，例如 `std::numeric_limits<long long>::max()`。不能从 `0` 开始，否则全为正数的区间会错误地得到 `0`。

## 第三步：怎样避免深链递归？

输入可能是一条有 200000 个节点的链，递归 DFS 会需要同样深度的函数调用。可以使用显式栈，给每个节点安排“进入”和“离开”两种事件。

<details>
<summary>实现提示：用进入、离开事件计算区间</summary>

先根据 `parent` 建立孩子列表，再把根的进入事件放入栈。每次取出栈顶事件：

- 如果是进入 `v`，记录 `tin[v]`，写入当前点权，并增加计数器。随后先压入 `v` 的离开事件，再压入各个孩子的进入事件。
- 如果是离开 `v`，记录此刻的计数器为 `tout[v]`。

栈后进先出，因此所有孩子事件及其后代都会在 `v` 的离开事件之前处理。若希望按孩子列表的正序访问，就按逆序压入孩子。

每个节点只有两个事件，每条父子边只用于安排一次孩子访问，因此遍历时间和额外空间都是 `O(n)`。线段树本身的递归深度只有 `O(log n)`，与原树的深链是不同的问题。

</details>

## 正确性与复杂度

DFS 区间恰好包含查询子树的所有节点。展平数组又让每个节点的当前点权对应唯一的位置；一次点赋值只改变这个位置。因此，只要线段树正确维护数组区间的最小值，它返回的就是当前子树的最小点权。

建立孩子列表、DFS 编号和线段树都需要 `O(n)` 时间。每次点赋值或区间查询需要 `O(log n)` 时间。若有 `m` 次操作，总时间为 `O(n + m log n)`，辅助空间为 `O(n)`。

编辑 [exercises/13.cppm](../exercises/13.cppm) 时，可以先输出纸上推演的 `tin`、`tout` 和展平数组，再接上线段树。重点检查：

1. 单节点树：查询得到它当前的点权，赋值后查询得到新值。
2. 查询叶子、根，以及只包含部分分支的内部节点。
3. 最小值被改大后，答案应转移到其他节点；点赋值不是取新旧值的最小值。
4. 多个节点具有相同最小值，以及负点权和全正点权。
5. 父编号大于子编号的输入、长链、空操作列表和只有修改的列表。
6. 同一个 `Solution` 对象的多次调用，计数器和所有数组都应重新初始化。
