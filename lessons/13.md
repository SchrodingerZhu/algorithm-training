# 13 · 子树 RMQ：DFS 序与点修改

进入每个顶点时只编号一次，子树对应连续区间 [tin[v],tout[v])。这里使用 DFS 序，不需要 LCA，也不需要 2n−1 长的 Euler Tour。

## 题目与接口

操作 {0,v,value} 点赋值；{1,v,0} 查询以固定根 0 定义的 v 的整棵子树最小点权。n、操作数≤200000。

```cpp
std::vector<long long> subtreeMin(const std::vector<int>& parent, const std::vector<long long>& values, const std::vector<std::array<long long, 3>>& operations);
```

parent=[-1,0,0,1]，values=[5,4,3,2]，操作 [[1,1,0],[0,3,8],[1,1,0],[1,0,0]] → [2,4,3]。

目标复杂度：O(n) 建立 DFS 序，每次操作 O(log n)。n 至少为 1，查询或操作列表允许为空。所有下标从 0 开始；所有输入符合题面约束，查询区间均合法。同一个 Solution 可重复调用，调用间不能保留旧数据。初始数组值、边权及点赋值的 value 默认在 ±10⁹ 内；专门注明更小界限时以题面为准。

parent 描述一棵合法的非空树，根为 0，parent[0]=-1；父编号不保证小于子编号。原树有长链时，应使用显式栈或其他安全遍历方式。
