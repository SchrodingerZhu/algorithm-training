# 第六课：从 μ 表到互质数对计数

这次题面不告诉你需要筛什么。先看输入、输出与约束，再挑选工具。

## 1. 主问题

实现 `long long Solution::countCoprimePairs(int n, int m)`，统计满足以下条件的**有序数对** (a,b)：

```text
1 ≤ a ≤ n
1 ≤ b ≤ m
gcd(a,b) = 1
```

`0≤n,m≤10⁶`；任一为 0 时答案为 0。要求 O(min(n,m)) 时间与空间。结果可能超过 int，必须使用 64 位整数。运行 `./judge 06`。

例：n=3、m=4 时答案为 9。按 a 分三行，贡献分别为 4、2、3。n=1、m=5 时答案为 5。

直接枚举需要 n*m 次 gcd，上界不合适。我们需要把“互质”替换成更容易一次计数的条件。

## 2. 分级提示

<details>
<summary>提示 1：把上一课的判断器用于 gcd</summary>

由 `Σ(d|x) μ(d)=[x=1]`，令 x=gcd(a,b)。d 整除 gcd(a,b)，等价于 d 同时整除 a 和 b。
</details>

<details>
<summary>提示 2：固定 d 时有多少对</summary>

1..n 中 d 的倍数有 floor(n/d) 个，1..m 中有 floor(m/d) 个。因此同时为 d 的倍数的有序数对有 `floor(n/d)*floor(m/d)` 个。
</details>

<details>
<summary>推导：交换有限求和顺序</summary>

```text
答案 = Σ(a=1..n) Σ(b=1..m) [gcd(a,b)=1]
     = Σ(a=1..n) Σ(b=1..m) Σ(d|a 且 d|b) μ(d)
     = Σ(d=1..min(n,m)) μ(d) floor(n/d) floor(m/d)
```

只需线性筛 μ 到 min(n,m)，再累加一次。每对 (a,b) 的总贡献恰好是上一课的 0/1 判断器，因此不会因为多个公因子而错误重复计数。

乘法应从开始就提升为 64 位，例如 `1LL * mu[d] * (n/d) * (m/d)`。仅让最后接收结果的变量为 long long，不能挽救已经发生的 int 乘法溢出。
</details>

## 3. 莫比乌斯反演的通用形式

熟悉上面的具体计数后，再看抽象。若 `F(n)=Σ(d|n) f(d)`，则：

```text
f(n) = Σ(d|n) μ(d) F(n/d)
```

展开右边并按 f(t) 合并，它的系数是 `Σ(d|n/t) μ(d)`，只有 t=n 时为 1，其余为 0。这就是反演的依据。不要把公式中的“约数和”换成普通的 1..n 前缀和。[进一步阅读](https://oi-wiki.org/math/number-theory/mobius/)

也可以定义狄利克雷卷积 `(f*g)(n)=Σ(d|n) f(d)g(n/d)`。常值函数 𝟙(n)=1 的逆是 μ，因为 `𝟙*μ=ε`，其中 ε(1)=1、其余为 0。这只是给同一计算起一个标准名称，不是新增一种筛法。

## 4. 做完后再选的变式

口头变式 A：若要求 gcd(a,b)=k，k≥1，把两数同时除以 k，范围变成 `floor(n/k)` 和 `floor(m/k)`。然后调用本题的计数方法。超过范围时结果自然为 0。

口头变式 B：若给定一个长度 ≤2000、值在 1..10⁶ 的正整数数组，统计下标 i<j 且 gcd(values[i],values[j])=1 的对。令 c[d] 为值能被 d 整除的元素数，则答案为 `Σ μ(d)*c[d]*(c[d]−1)/2`；这里是无序下标对，不能沿用本题的 n/d*m/d。先用 [2,3,4] 手算，答案应为 2。这两道变式未配置独立自动评测。

## 5. 以后需要更快求和时

本题一次求和 O(min(n,m)) 已足够，不需要抢先优化。若已预处理 μ 的普通前缀和 M，并要做多次求和，可把 `floor(n/d)`、`floor(m/d)` 同时不变的一段 [l,r] 合并：

```text
q1 = n/l, q2 = m/l
r  = min(n/q1, m/q2, min(n,m))
贡献 = (M[r]−M[l−1]) * q1 * q2
下一段从 r+1 开始
```

非空范围内 q1、q2 均非零。段数可由两个整除商变化点集合界定为 O(√n+√m)，也不会多于 min(n,m)。但预处理仍然占 O(min(n,m))，不能把单次完整算法直接宣称为平方根时间。杜教筛、分段筛属于后续主题，等这些基础稳定后再引入。
