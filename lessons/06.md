# 06 · 离线 RMQ：单调栈与并查集

扫到右端点 r 时，用单调栈把已被更小的右侧元素淘汰的下标连向新代表。此时 find(l) 指向 [l,r] 中一个最小值位置。

## 题目与接口

同 02 的静态 RMQ 接口，n,q≤200000。所有查询一次给出；要求按右端点离线处理，不用 ST 或 LCA。

```cpp
std::vector<long long> rangeMin(const std::vector<long long>& values, const std::vector<std::array<int, 2>>& queries);
```

[5,3,4,1]，查询 [[0,2],[1,3],[2,2]] → [3,1,4]。

目标复杂度：O((n+q) α(n)) 时间，O(n+q) 空间。n 至少为 1，查询或操作列表允许为空。所有下标从 0 开始；所有输入符合题面约束，查询区间均合法。同一个 Solution 可重复调用，调用间不能保留旧数据。初始数组值、边权及点赋值的 value 默认在 ±10⁹ 内；专门注明更小界限时以题面为准。
