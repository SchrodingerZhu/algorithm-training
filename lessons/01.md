# 01 · RMQ 基线：直接扫描

RMQ 是 Range Minimum Query。先固定下标、边界和空区间约定，再讨论加速。这份朴素算法以后可以作为随机对拍的判定器。

## 题目与接口

给定数组和若干闭区间 [l,r]，按顺序返回最小值。1≤n≤2000，0≤q≤2000。

```cpp
std::vector<long long> rangeMin(const std::vector<long long>& values, const std::vector<std::array<int, 2>>& queries);
```

[5,2,2,7]，查询 [[0,3],[2,2],[1,2]] → [2,2,2]。

目标复杂度：每次 O(r−l+1)，额外空间 O(1)，输出另计。n 至少为 1，查询或操作列表允许为空。所有下标从 0 开始；所有输入符合题面约束，查询区间均合法。同一个 Solution 可重复调用，调用间不能保留旧数据。初始数组值、边权及点赋值的 value 默认在 ±10⁹ 内；专门注明更小界限时以题面为准。
