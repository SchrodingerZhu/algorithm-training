# 12 · 换根 LCA：不重建整棵树

树的无向边和路径没有改变，只是祖先方向改变。原根下的三个 LCA：a=LCA(u,v)、b=LCA(u,r)、c=LCA(v,r)，足以定位新答案。

## 题目与接口

每个查询 {r,u,v} 临时把根换成 r，返回此根下的 LCA(u,v)。查询之间互不影响；n,q≤200000。

```cpp
std::vector<int> rerootedLca(const std::vector<int>& parent, const std::vector<std::array<int, 3>>& queries);
```

parent=[-1,0,0,1,1]，查询 [[0,3,4],[3,2,4],[4,3,2]] → [1,1,1]。

目标复杂度：一次 O(n log n) 预处理，每次 O(log n)。n 至少为 1，查询或操作列表允许为空。所有下标从 0 开始；所有输入符合题面约束，查询区间均合法。同一个 Solution 可重复调用，调用间不能保留旧数据。初始数组值、边权及点赋值的 value 默认在 ±10⁹ 内；专门注明更小界限时以题面为准。

parent 描述一棵合法的非空树，根为 0，parent[0]=-1；父编号不保证小于子编号。原树有长链时，应使用显式栈或其他安全遍历方式。
