# 第五课：莫比乌斯函数就是带符号的平方因子检查

前面已经练过两个分支。本课的 μ 筛法反而更短；先弄懂它为什么取 0、1、−1。

## 1. 从定义计算几个数

```text
μ(1) = 1
含有任意质数的平方因子：μ(x) = 0
否则 x 是 k 个不同质数的乘积：μ(x) = (−1)^k
```

例如 μ(2)=−1，μ(6)=1，μ(30)=−1，μ(12)=0。12 中有 2²，所以不能仅凭“不同质因子有两个”就判断为 1。[定义与性质参考](https://oi-wiki.org/math/number-theory/mobius/)

先手算 μ(1..10)，再写筛法。

## 2. 自己推导转移

质数 p 的 μ(p)=−1。

若 p 不整除 i，添一个新质因子：原来平方自由时，符号翻转；原来已有平方因子时，仍为 0。这两者统一为 `μ(i*p)=-μ(i)`。

若 p 整除 i，i*p 必含 p²，所以 `μ(i*p)=0`，然后 break。

检查 `10×3` 与 `15×2` 时，数学上的乘法推导都成立，但欧拉筛真正生成 30 的只有后者。函数性质和枚举限制是两件都需要检查的事。

## 3. 主练习

实现 `Solution::mobius(int n)`，返回 μ[0..n]，以 μ[0]=0 为哨兵，n≥1 时 μ[1]=1。`0≤n≤10⁶`，O(n) 时间与空间。

例：n=10，返回 `[0,1,-1,-1,0,-1,1,-1,0,0,1]`。运行 `./judge 05`。

<summary>提示：最容易漏掉的两点</summary>

μ(1) 必须单独初始化；重复质因子的分支不仅要置零，还要保留欧拉筛的 break。不设 break 即使最后恰好仍算对某些值，也失去了唯一生成的保证。

## 4. 为什么这种符号有用

对任意正整数 x：

```text
Σ(d | x) μ(d) = 1（x=1）；否则为 0。
```

只看 x 的 k 个不同质因子。带平方因子的约数没有贡献；其余约数对应“挑选一个质因子子集”，选 j 个的贡献为 (−1)^j。总和是 `(1−1)^k`。x=1 对应空子集，和为 1。

这相当于一个精确的判断器：用约数求和，就能判定 x 是否等于 1。下一课把 x 换成 gcd(a,b)，便能把互质限制变成可计数的倍数条件。

可选口头题：计算 `μ(1)+μ(2)+μ(3)+μ(6)`，再对 12 的全部约数求和。这里是约数和，不是 1..x 的普通前缀和。
