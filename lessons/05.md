# 05 · 区间加与区间最小值

区间所有值加 d 时，区间最小值也加 d。懒标记记录尚未传给孩子的增量，多次增量应相加。

## 题目与接口

操作 {0,l,r,delta} 给区间全体加 delta；{1,l,r,0} 查询最小值。n、操作数≤200000，|delta|≤10⁶。

```cpp
std::vector<long long> rangeAddMin(const std::vector<long long>& values, const std::vector<std::array<long long, 4>>& operations);
```

[5,2,7]，操作 [[0,0,1,3],[1,0,2,0],[0,1,2,-10],[1,0,2,0]] → [5,-5]。

目标复杂度：建树 O(n)，每次操作 O(log n)，空间 O(n)。n 至少为 1，查询或操作列表允许为空。所有下标从 0 开始；所有输入符合题面约束，查询区间均合法。同一个 Solution 可重复调用，调用间不能保留旧数据。初始数组值、边权及点赋值的 value 默认在 ±10⁹ 内；专门注明更小界限时以题面为准。
