# 14 · 树链剖分：路径最小点权

每点选子树最大的孩子为重儿子，连续重边形成重链。任何向根路径只跨 O(log n) 条轻边；链内位置连续，可交给线段树。

## 题目与接口

操作 {0,v,value} 点赋值；{1,u,v} 查询 u 到 v 路径（含两端）的最小点权。n、操作数≤200000。

```cpp
std::vector<long long> pathMinUpdates(const std::vector<int>& parent, const std::vector<long long>& values, const std::vector<std::array<long long, 3>>& operations);
```

parent=[-1,0,0,1]，values=[5,4,3,2]，操作 [[1,3,2],[0,1,-7],[1,3,2],[1,2,2]] → [2,-7,3]。

目标复杂度：O(n) 分解，点赋值 O(log n)，路径查询 O(log² n)。n 至少为 1，查询或操作列表允许为空。所有下标从 0 开始；所有输入符合题面约束，查询区间均合法。同一个 Solution 可重复调用，调用间不能保留旧数据。初始数组值、边权及点赋值的 value 默认在 ±10⁹ 内；专门注明更小界限时以题面为准。

parent 描述一棵合法的非空树，根为 0，parent[0]=-1；父编号不保证小于子编号。原树有长链时，应使用显式栈或其他安全遍历方式。
