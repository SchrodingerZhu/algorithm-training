# 08 · 二进制提升求 LCA

LCA 是同时为两点祖先且深度最大的点。先把深点抬到相同深度，再一起抬到 LCA 的两个孩子。

## 题目与接口

查询 {u,v} 返回根为 0 时最近公共祖先。parent 定义同 07；n,q≤200000。

```cpp
std::vector<int> lca(const std::vector<int>& parent, const std::vector<std::array<int, 2>>& queries);
```

parent=[-1,0,0,1,1,2]，查询 [[3,4],[3,5],[1,3],[2,2]] → [1,0,1,2]。

目标复杂度：预处理 O(n log n)，每次 O(log n)。n 至少为 1，查询或操作列表允许为空。所有下标从 0 开始；所有输入符合题面约束，查询区间均合法。同一个 Solution 可重复调用，调用间不能保留旧数据。初始数组值、边权及点赋值的 value 默认在 ±10⁹ 内；专门注明更小界限时以题面为准。

parent 描述一棵合法的非空树，根为 0，parent[0]=-1；父编号不保证小于子编号。原树有长链时，应使用显式栈或其他安全遍历方式。
