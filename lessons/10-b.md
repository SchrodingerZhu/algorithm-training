# 10-b · Cartesian Tree：所有子数组的最小值之和

本题利用笛卡尔树，把二次数量的子数组分配给各个节点，再在线性时间内累加贡献。建树之后只需统计左右子树大小，无需 LCA 查询表。

## 题目与函数接口

给定非空数组 `values`。子数组是一个非空连续区间 `[l, r]`，包含两端；不同的位置区间分别计数，即使其中的元素完全相同。

对每个子数组求其中的最小值，再把这些最小值相加，返回总和：

```text
answer = 对所有 0 ≤ l ≤ r < n，累加 min(values[l], ..., values[r])
```

在 `Solution` 类中实现：

```cpp
long long sumSubarrayMinimums(const std::vector<long long> &values);
```

- `1 ≤ n = values.size() ≤ 200000`。
- `-10⁶ ≤ values[i] ≤ 10⁶`，允许负数、零和重复值。
- 返回精确总和，**不取模**；答案可能为负数。
- 本题没有额外的查询列表，需要统计所有非空子数组。
- 同一个 `Solution` 对象可被多次调用，每次应独立计算。
- 本题练习构造最小笛卡尔树，再计算每个节点的贡献。
- 目标时间 `O(n)`，辅助空间 `O(n)`。

## 手算例子

对于 `values = [3, 1, 2]`，一共有 `3 × 4 / 2 = 6` 个非空子数组：

| 区间 | 子数组 | 最小值 |
|---|---|---|
| `[0, 0]` | `[3]` | 3 |
| `[1, 1]` | `[1]` | 1 |
| `[2, 2]` | `[2]` | 2 |
| `[0, 1]` | `[3, 1]` | 1 |
| `[1, 2]` | `[1, 2]` | 1 |
| `[0, 2]` | `[3, 1, 2]` | 1 |

答案为 `3 + 1 + 2 + 1 + 1 + 1 = 9`。

对于 `[2, 2, 2]`，六个子数组的最小值都是 `2`，返回 `12`。这里每个区间只贡献一次，不会因为同一个最小值在该区间出现多次，就重复累加。

对于 `[-2, 5, -2]`，三个长度为 1 的子数组贡献 `-2 + 5 - 2 = 1`，两个长度为 2 的子数组贡献 `-4`，整个数组贡献 `-2`，总和为 `-5`。

## 为什么要给相等的值规定顺序？

为了统计贡献，我们把每个子数组分配给一个节点：选出该子数组中所有取得最小值的位置，将子数组分配给其中下标最小的节点。

这只是确保每个子数组恰好被计数一次的规则，不改变其最小值。例如 `[2, 2]` 的三个子数组，`[0, 0]` 和 `[0, 1]` 分配给节点 `0`，`[1, 1]` 分配给节点 `1`，总贡献为 `2 × 2 + 2 × 1 = 6`。

## 需要怎样的笛卡尔树？

把数组下标 `i` 作为节点编号，节点携带 `values[i]`。构造一棵满足以下两条性质的二叉树：

1. 左子树所有下标小于当前下标，右子树所有下标大于当前下标。按“左子树、当前节点、右子树”的中序遍历，输出全部下标的递增序列。
2. 父节点的 `(values[i], i)` 小于孩子的对应二元组，先比较值，值相等再比较下标。

这是本题的最小笛卡尔树。每棵子树对应一个连续区间，子树根的值是该区间的最小值；如果该值出现多次，根的下标是这些位置中最小的。树不要求平衡，根可以是任意下标。

主例 `[3, 1, 2]` 的树如下，节点标成 `下标:值`：

```text
       1:1
      /   \
    0:3   2:2
```

## 实现提示

<details>
<summary>提示 1：建树时怎样处理重复值？</summary>

按下标从左到右处理，使用栈保存当前树从根开始不断走向右孩子的路径。左右孩子初始为 `-1`，表示不存在。

插入新节点 `i` 时，弹出所有值严格大于 `values[i]` 的栈顶节点，记录最后弹出的节点 `last`。栈还非空时，把 `i` 设为剩余栈顶的右孩子；发生过弹栈时，把 `last` 设为 `i` 的左孩子；最后将 `i` 入栈。全部完成后，栈底是根。

相等时不弹栈，让较早的下标保留在上方，与子数组的分配规则一致。每个节点只入栈一次、最多出栈一次，建树为 `O(n)`。可以复用第 10 题的建树部分。

</details>

<details>
<summary>提示 2：一个节点会分到多少个子数组？</summary>

设节点 `i` 的子树覆盖 `[a, b]`。由于中序顺序，它的左子树覆盖 `[a, i-1]`，右子树覆盖 `[i+1, b]`。

所有满足以下条件的子数组都分配给 `i`：

```text
a ≤ l ≤ i ≤ r ≤ b
```

它们包含 `i`，且其他节点的 `(值, 下标)` 都大于节点 `i` 的二元组。反过来，分配给 `i` 的区间一定在它的子树内：从根开始，若当前根在区间外，就进入包含整个区间的那侧；第一次遇到位于区间内的根时，堆性质使它成为该区间选中的节点，也就是 `i`。

设左右子树大小分别为 `L` 和 `R`，则起点有 `L + 1` 种选择，终点有 `R + 1` 种选择，两者独立。因此：

```text
分配给节点 i 的子数组个数 = (L + 1) × (R + 1)
节点 i 的贡献 = values[i] × (L + 1) × (R + 1)
```

累加所有节点的贡献就是答案。主例中，节点 `1` 左右各有一个节点，贡献 `1 × 2 × 2 = 4`；两个叶子分别贡献 `3` 和 `2`，总和为 `9`。

</details>

<details>
<summary>提示 3：怎样统计子树大小并避免深链递归？</summary>

空子树大小为 `0`，非空节点满足：

```text
size[i] = 1 + size[left[i]] + size[right[i]]
```

可以用显式栈生成父节点先于孩子的遍历顺序，然后倒序处理。在处理节点 `i` 时，两个孩子的大小已经算好，此时就能计算 `size[i]` 和节点贡献。

不要直接按下标倒序来代替这个遍历：父节点的下标可能大于孩子，也可能小于孩子。单调或全相等数组会形成深链，应避免依赖深度为 `n` 的函数递归。

还可以用下面的等式检查计数是否遗漏或重复：

```text
对所有节点累加 (L + 1) × (R + 1) = n × (n + 1) / 2
```

</details>

## 数值范围与测试

非空子数组共有 `n(n+1)/2` 个，因此答案的绝对值不超过：

```text
10⁶ × 200000 × 200001 / 2 = 20,000,100,000,000,000
```

这个范围能放进有符号 64 位整数。中间的计数乘法也应使用 64 位整数。如果子树大小用 `std::size_t` 保存，应先转为 `long long` 再乘，避免负值参与无符号运算。

测试包括题面例子、单点、重复值、负值、固定种子的随机数组与朴素枚举对拍，以及 200000 个元素的递增、递减、全相等和正负交替输入。大规模测试也检查计数和答案是否溢出。测试不能替代对算法复杂度和计数规则的解释。
