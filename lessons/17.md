# 17 · LCT：动态森林连通性

实际森林与辅助 Splay 是两种结构。辅助树的根仍可能有路径父亲，所以不能用 parent==0 判断辅助树根。access 重新选择首选路径；makeroot 用路径翻转改变根。

## 题目与接口

初始 n 个孤立点。{0,u,v} link；{1,u,v} cut；{2,u,v} 查询是否连通，输出 0/1。会成环的 link、自环及不存在的边 cut 均忽略。cut 只能删直接边，不能删整条路径。n≤100000，操作数≤200000。

```cpp
std::vector<int> dynamicConnectivity(int n, const std::vector<std::array<int, 3>>& operations);
```

n=3，操作 [[0,0,1],[0,1,2],[2,0,2],[1,0,2],[2,0,2],[1,1,2],[2,0,2]] → [1,1,0]。

目标复杂度：每次操作均摊 O(log n)，空间 O(n)。n 至少为 1，查询或操作列表允许为空。所有下标从 0 开始；所有输入符合题面约束，查询区间均合法。同一个 Solution 可重复调用，调用间不能保留旧数据。初始数组值、边权及点赋值的 value 默认在 ±10⁹ 内；专门注明更小界限时以题面为准。
