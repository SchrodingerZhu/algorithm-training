# 18 · LCT 综合：动态路径点权和

在 17 的辅助树节点中维护 val 与 sum。makeroot(u)、access(v) 之后，v 所在的辅助树恰表示 u 到 v 的路径，sum[v] 就是答案。此处仅求路径，不维护虚子树统计。

## 题目与接口

初始为孤立点，点权给定。{0,u,v} link；{1,u,v} cut；{2,u,value} 点赋值；{3,u,v} 查询路径和。连断规则同 17。只为查询输出，断开时返回 std::nullopt，连通时返回含两端的和。n≤100000，操作数≤200000。

```cpp
std::vector<std::optional<long long>> dynamicPathSum(const std::vector<long long>& values, const std::vector<std::array<long long, 3>>& operations);
```

values=[2,-1,4]，操作 [[3,0,2],[0,0,1],[0,1,2],[3,0,2],[2,1,5],[3,2,0],[1,1,2],[3,0,2]] → [nullopt,5,11,nullopt]。

目标复杂度：每次操作均摊 O(log n)，空间 O(n)。n 至少为 1，查询或操作列表允许为空。所有下标从 0 开始；所有输入符合题面约束，查询区间均合法。同一个 Solution 可重复调用，调用间不能保留旧数据。初始数组值、边权及点赋值的 value 默认在 ±10⁹ 内；专门注明更小界限时以题面为准。
