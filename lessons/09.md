# 09 · Euler Tour 把 LCA 变为 RMQ

每次进入节点、从孩子返回节点都记录它，序列长 2n−1。两点首次出现位置之间深度最小的顶点就是 LCA。仅记录每点一次的 DFS 序不够。

## 题目与接口

同 08 的输入与输出。要求使用完整 Euler Tour 的深度 RMQ，而不是祖先倍增查询。

```cpp
std::vector<int> lca(const std::vector<int>& parent, const std::vector<std::array<int, 2>>& queries);
```

parent=[-1,0,0,1,1]，查询 [[3,4],[2,4]] → [1,0]。

目标复杂度：预处理 O(n log n)，每次 O(1)，空间 O(n log n)。n 至少为 1，查询或操作列表允许为空。所有下标从 0 开始；所有输入符合题面约束，查询区间均合法。同一个 Solution 可重复调用，调用间不能保留旧数据。初始数组值、边权及点赋值的 value 默认在 ±10⁹ 内；专门注明更小界限时以题面为准。

parent 描述一棵合法的非空树，根为 0，parent[0]=-1；父编号不保证小于子编号。原树有长链时，应使用显式栈或其他安全遍历方式。
