# 04 · 点修改与区间最小值

ST 的预处理依赖静态数组。线段树把区间分层，每次单点赋值只改变一条祖先链；点赋值不是加法。

## 题目与接口

操作 {0,index,value} 把单点赋值；{1,l,r} 查询闭区间最小值。只为查询输出。n、操作数≤200000。

```cpp
std::vector<long long> rangeMinUpdates(const std::vector<long long>& values, const std::vector<std::array<long long, 3>>& operations);
```

[5,2,7]，操作 [[1,0,2],[0,1,9],[1,0,2]] → [2,5]。

目标复杂度：建树 O(n)，每次操作 O(log n)，空间 O(n)。n 至少为 1，查询或操作列表允许为空。所有下标从 0 开始；所有输入符合题面约束，查询区间均合法。同一个 Solution 可重复调用，调用间不能保留旧数据。初始数组值、边权及点赋值的 value 默认在 ±10⁹ 内；专门注明更小界限时以题面为准。
