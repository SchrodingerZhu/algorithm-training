# 11 · 树上 RMQ：倍增聚合路径边最小值

在 up 表旁增加 mn[j][v]，保存这段 2^j 步中的最小边权。可以边抬点边聚合，不必先单独调用一个 LCA 函数。

## 题目与接口

edgeWeight[v] 是 parent[v] 到 v 的边权，根的权值忽略。查询路径上的最小边权；u=v 时约定返回 0。n,q≤200000。

```cpp
std::vector<long long> pathMin(const std::vector<int>& parent, const std::vector<long long>& edgeWeight, const std::vector<std::array<int, 2>>& queries);
```

parent=[-1,0,0,1]，edgeWeight=[0,5,2,-3]，查询 [[3,2],[1,3],[0,0]] → [-3,-3,0]。

目标复杂度：预处理 O(n log n)，每次 O(log n)。n 至少为 1，查询或操作列表允许为空。所有下标从 0 开始；所有输入符合题面约束，查询区间均合法。同一个 Solution 可重复调用，调用间不能保留旧数据。初始数组值、边权及点赋值的 value 默认在 ±10⁹ 内；专门注明更小界限时以题面为准。

parent 描述一棵合法的非空树，根为 0，parent[0]=-1；父编号不保证小于子编号。原树有长链时，应使用显式栈或其他安全遍历方式。
