# 10 · Cartesian Tree：把 RMQ 变为 LCA

Cartesian Tree 同时满足：中序遍历下标递增，父亲的 (值,下标) 小于孩子。区间两端的 LCA 就是区间 argmin。根不一定是下标 0。

## 题目与接口

返回每个区间最小值的下标；并列时取最左下标。n,q≤200000。要求构造最小 Cartesian Tree，再用 LCA。

```cpp
std::vector<int> argMin(const std::vector<long long>& values, const std::vector<std::array<int, 2>>& queries);
```

[3,1,1,2]，查询 [[0,3],[2,3],[0,0]] → [1,2,0]。

目标复杂度：Cartesian Tree O(n)；LCA 预处理 O(n log n)，查询 O(log n) 或 O(1)。n 至少为 1，查询或操作列表允许为空。所有下标从 0 开始；所有输入符合题面约束，查询区间均合法。同一个 Solution 可重复调用，调用间不能保留旧数据。初始数组值、边权及点赋值的 value 默认在 ±10⁹ 内；专门注明更小界限时以题面为准。
