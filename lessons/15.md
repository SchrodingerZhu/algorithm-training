# 15 · 树链剖分：路径加与路径和

保留 14 的分段方式，把线段树统计换成 sum。长度为 len 的整段加 d，会让 sum 增加 len*d。

## 题目与接口

操作 {0,u,v,delta} 给路径上每个点加 delta；{1,u,v,0} 查询路径点权和。n、操作数≤200000，|初值|,|delta|≤10⁶。

```cpp
std::vector<long long> pathAddSum(const std::vector<int>& parent, const std::vector<long long>& values, const std::vector<std::array<long long, 4>>& operations);
```

parent=[-1,0,0]，values=[1,2,3]，操作 [[1,1,2,0],[0,1,2,4],[1,1,2,0],[1,0,0,0]] → [6,18,5]。

目标复杂度：预处理 O(n)，每次操作 O(log² n)。n 至少为 1，查询或操作列表允许为空。所有下标从 0 开始；所有输入符合题面约束，查询区间均合法。同一个 Solution 可重复调用，调用间不能保留旧数据。初始数组值、边权及点赋值的 value 默认在 ±10⁹ 内；专门注明更小界限时以题面为准。

parent 描述一棵合法的非空树，根为 0，parent[0]=-1；父编号不保证小于子编号。原树有长链时，应使用显式栈或其他安全遍历方式。
