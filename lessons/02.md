# 第二课：怎样在筛法里统计自己的数据

进入本课前，先解释第一课的 `break`。不清楚时先回到 12 和 18 的例子。

## 1. 不先套积性函数公式

线性筛已经给每个合数安排了一次生成事件 `x=i*p`。i 比 x 小，我们可以在这一刻从 i 的数据推导 x 的数据。只要一次转移耗时 O(1)，总时间仍是 O(n)。这和沿依赖顺序做 DP 很相似。

先统计两种量：ω(x) 表示不同质因子的个数；Ω(x) 表示把重复也算进去的个数。例如 `12=2²×3`，所以 `ω(12)=2`，`Ω(12)=3`。两者在 1 上都为 0。

## 2. 唯一需要区分的两种情况

合法枚举中只有 `p < lp[i]` 或 `p = lp[i]`。

如果 `p < lp[i]`，p 之前没有出现，是一个新质因子。例如 `15 × 2 = 30`。两个计数都加 1。

如果 `p = lp[i]`，只是原有质因子的指数加 1。例如 `6 × 2 = 12`。不同质因子个数不变，总个数加 1。更新完再 `break`。

| 情况 | ω(i×p) | Ω(i×p) |
|---|---|---|
| i 为新发现的质数（初始化） | ω(i)=1 | Ω(i)=1 |
| p 不整除 i | ω(i)+1 | Ω(i)+1 |
| p 整除 i | ω(i) | Ω(i)+1 |

自己核对 `8→16`、`15→30`、`9→18`。第三个例子是在给一个合数添上新的质因子。

## 3. 主练习

实现 `Solution::factorCounts(int n)`，返回长 n+1 的数组，每项为 `{ω(x), Ω(x)}`，下标 0 和 1 均为 `{0,0}`。约束 `0≤n≤10⁶`，O(n) 时间与空间。

例：n=6，返回 `{{0,0},{0,0},{1,1},{1,1},{1,2},{1,1},{2,2}}`。运行 `./judge 02`。

## 4. 抽象成题目接口

现在设题目只问：“1 到 n 中，恰有 k 种不同质因子的数有多少个？” 接口可以是 `int countWithKDistinctPrimeFactors(int n, int k)`。筛表是内部工具，答案只是对 `ω(x)==k` 的计数。

可选短变式（口头，未提供独立测试）：n=10、k=2 时答案是 2，对应 6、10。若 k=0，应如何处理 1？

## 5. 什么数据都能直接乘吗

不能。ω 满足互质时相加，而非相乘。更一般地，你应问：新添质数时如何更新？重复质数时如何更新？手里的状态是否足够？

后面会学习：积性函数 f 在互质时满足 `f(ab)=f(a)f(b)`；但同一质数的幂次增加时仍需单独推导。线性筛提供遍历方式，不替你保证递推公式正确。
