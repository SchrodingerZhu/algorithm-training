# 02 · Sparse Table：幂等 RMQ

st[k][i] 表示从 i 起长度 2^k 的区间最小值。倍增长度让任意区间可由两个等长块覆盖；两块可能重叠。

## 题目与接口

与 01 的接口相同，扩大到 n,q≤200000。数组静态，要求使用 Sparse Table（ST 表）。

```cpp
std::vector<long long> rangeMin(const std::vector<long long>& values, const std::vector<std::array<int, 2>>& queries);
```

[8,-1,4,3]，查询 [[0,3],[2,3],[1,1]] → [-1,3,-1]。

目标复杂度：预处理 O(n log n)，查询 O(1)，空间 O(n log n)。n 至少为 1，查询或操作列表允许为空。所有下标从 0 开始；所有输入符合题面约束，查询区间均合法。同一个 Solution 可重复调用，调用间不能保留旧数据。初始数组值、边权及点赋值的 value 默认在 ±10⁹ 内；专门注明更小界限时以题面为准。

## 动手顺序

先手算例子，写清维护量及其含义，再实现主操作。最后检查单点、重复最小值、负值、边界以及题目允许的空操作列表。

<details>
<summary>提示 1</summary>

st[0][i]=values[i]；st[k][i]=min(st[k−1][i],st[k−1][i+2^(k−1)])。
</details>

<details>
<summary>提示 2</summary>

取 k=floor(log2(r−l+1))，组合 st[k][l] 与 st[k][r−2^k+1]。
</details>

<details>
<summary>提示 3：正确性与常见错误</summary>

min(x,x)=x，所以重叠不影响答案；普通区间和不能照搬这一查询公式。
</details>
