# 07 · 倍增祖先表：第 k 个祖先

up[j][v] 表示向上走 2^j 步后的顶点。它与 ST 都用倍增，却存的是函数复合，不是区间聚合。父编号不保证小于子编号。

## 题目与接口

根为 0，parent[0]=-1。查询 {v,k} 返回第 k 个祖先，k=0 返回 v，越过根返回 -1。n,q≤200000，0≤k≤10¹⁸。

```cpp
std::vector<int> kthAncestors(const std::vector<int>& parent, const std::vector<std::array<long long, 2>>& queries);
```

parent=[-1,0,0,1]，查询 [[3,0],[3,1],[3,2],[3,3]] → [3,1,0,-1]。

目标复杂度：预处理 O(n log n)，每次 O(log n)。n 至少为 1，查询或操作列表允许为空。所有下标从 0 开始；所有输入符合题面约束，查询区间均合法。同一个 Solution 可重复调用，调用间不能保留旧数据。初始数组值、边权及点赋值的 value 默认在 ±10⁹ 内；专门注明更小界限时以题面为准。

parent 描述一棵合法的非空树，根为 0，parent[0]=-1；父编号不保证小于子编号。原树有长链时，应使用显式栈或其他安全遍历方式。
