# 03 · 固定窗口 RMQ：单调队列

查询窗口依次向右移动，不需要通用 ST。一个更靠右、值更小的元素可以永久淘汰队尾候选。队列保存下标，才能判断过期。

## 题目与接口

返回每个长度恰为 k 的连续窗口最小值。1≤k≤n≤200000，输出 n−k+1 项。

```cpp
std::vector<long long> windowMin(const std::vector<long long>& values, int k);
```

[4,2,2,5,1]，k=3 → [2,2,1]。

目标复杂度：总时间 O(n)，额外空间 O(k)，输出另计。n 至少为 1，查询或操作列表允许为空。所有下标从 0 开始；所有输入符合题面约束，查询区间均合法。同一个 Solution 可重复调用，调用间不能保留旧数据。初始数组值、边权及点赋值的 value 默认在 ±10⁹ 内；专门注明更小界限时以题面为准。
