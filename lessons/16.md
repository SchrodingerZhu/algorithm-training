# 16 · LCT 前置：隐式 Splay 与区间翻转

隐式 Splay 按左子树大小定位第 k 个元素，不按元素值排序。旋转维护父子关系、size 与 sum；翻转用交换左右孩子和异或 rev 标记表示。

## 题目与接口

操作 {0,l,r} 翻转当前序列闭区间；{1,l,r} 查询当前区间和。下标指当前序列位置。n、操作数≤100000。要求使用隐式 Splay。

```cpp
std::vector<long long> reverseSum(const std::vector<long long>& values, const std::vector<std::array<int, 3>>& operations);
```

[1,2,3,4]，操作 [[0,0,2],[1,0,1],[0,1,3],[1,0,1]] → [5,7]。

目标复杂度：每次操作均摊 O(log n)，空间 O(n)。n 至少为 1，查询或操作列表允许为空。所有下标从 0 开始；所有输入符合题面约束，查询区间均合法。同一个 Solution 可重复调用，调用间不能保留旧数据。初始数组值、边权及点赋值的 value 默认在 ±10⁹ 内；专门注明更小界限时以题面为准。

## 动手顺序

先手算例子，写清维护量及其含义，再实现主操作。最后检查单点、重复最小值、负值、边界以及题目允许的空操作列表。

<details>
<summary>提示 3：正确性与常见错误</summary>

旋转前按祖先到后代顺序 push 懒标记；旋转后先 pull 旧父亲再 pull 新父亲。翻转不改变区间和，但改变顺序。
</details>
